Nader Sleiman Portfolio
=======================

A static HTML portfolio with no build step or dependencies.

Files
-----
- index.html
- css/style.css
- js/script.js
- images/
- Nader-Sleiman-CV.pdf

Run locally
-----------
Open index.html in a browser, or run:
  python3 -m http.server 8000
Then visit http://localhost:8000

Publish for free with Netlify
-----------------------------
1. Keep this whole folder together.
2. Go to https://app.netlify.com/drop
3. Drag this folder into the upload area.
4. Netlify will provide a public .netlify.app URL.

Publish with GitHub Pages
-------------------------
1. Create a public GitHub repository.
2. Upload all files in this folder.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and /root, then save.

Important
---------
Do not upload only index.html. The css, js, images, and CV files must remain beside it.
